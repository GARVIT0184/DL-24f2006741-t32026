# Industrial Surface Defect Detection

**Course:** Introduction to DL and GenAI Project (BSDA2001P)  
**Project:** Industrial Surface Anomaly Segmentation  
**Repository:** DL-24f2006741-T3-2026

## Project Overview

This project focuses on analysing industrial surface defect data and preparing a segmentation baseline for identifying defects in images.

The dataset contains images at a native resolution of **128 × 800 pixels** and four defect classes: `defect_a`, `defect_b`, `defect_c`, and `defect_d`.

## Dataset Details

- **Image resolution:** 128 × 800 pixels
- **Defect classes:** `defect_a`, `defect_b`, `defect_c`, `defect_d`
- **Mask format:** Run-Length Encoding (RLE)
