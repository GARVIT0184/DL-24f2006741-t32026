# Industrial Surface Defect Detection

**Course:** Introduction to DL and GenAI Project (BSDA2001P)  
**Project:** Industrial Surface Anomaly Segmentation

## Overview

Image segmentation project for detecting four industrial defect classes: `defect_a`, `defect_b`, `defect_c` and `defect_d`.

Dataset images have a resolution of **128 × 800 pixels** with masks stored in RLE format.
